# TouchPadFC v11 — Controls guide

> Mappings are **controller input commands** sent to the Windows receiver, not proof of the resulting EA FC 27 animation. The game may interpret inputs differently according to Classic/Alternative settings, defending mode, context, and player ratings.

## Four main match buttons (ATTACK)

| iPhone action | Sent virtual PlayStation-style input |
|---|---|
| Move | Left stick |
| Hold DASH | R2 |
| Swipe DASH left | R1 controlled sprint |
| Double-tap DASH | L1 + R1 (proposed Curved Run gesture) |
| Tap PASS | × |
| Swipe PASS up | □ normal cross |
| Swipe PASS left | L1 + × pass and go |
| Swipe PASS right | R1 + × driven pass |
| Swipe PASS down | L1 + R1 + × Pass & Follow |
| Double-tap PASS | Pass & Follow (unless Instant PASS enabled) |
| Tap THROUGH | △ |
| Double-tap THROUGH | △, △ dinked through |
| Swipe THROUGH up | L1 + △ lobbed through |
| Hold SHOOT | ○ charged shot |
| Swipe SHOOT left then hold | R1 + ○ finesse / curve |
| Swipe SHOOT up then hold | L1 + ○ chip |
| Swipe SHOOT right then hold | L1 + R1 + ○ power |
| Swipe SHOOT down | ○ then × fake shot |
| Charge/release SHOOT then tap again | Attempt second ○ for low-driven |
| Double-tap CANCEL ×2 | L1 + R1 + L2 + R2 (Hard Super Cancel attempt) |

## SKILLS / TACTICS / ACTIONS

Tap the corresponding small match-screen menu; choose a category or search by name. Tap to trigger a sequence, or touch and hold for continuous actions. ★ marks favorites. The action list includes crossing variants, fake pass, shooting variants, movement, teammate runs, goalkeeper controls and set-piece actions. Selected moves are highly context dependent and may not work with every player. Some catalog entries are experimental mappings.

For scripted right-stick moves, set **PLAYER FACES** to the direction your footballer faces. Inputs are **relative to player direction**; they are not position-tracked. Star requirements still apply. Do not assume every listed combination is fully FC 27 verified.

## Joystick and button size

- **PC → Movement Joystick**: Fixed or Floating.
- **PC → Button Size**: global scale 80–125%.
- **EDIT**: drag each match control and adjust selected control from 55–190%.
- **PC → Quick Buttons**: two selected actions on the main screen.

## Set pieces

Top GAME MODE menu provides Match, Penalty Shoot, Penalty Save, Free Kick and Corner. EXTRAS opens additional commands. Return to MATCH afterward; automatic set-piece detection does not exist.

## Limitations

- The receiver uses unencrypted local UDP with a six-digit pairing PIN; keep on trusted private LAN.
- The screen-based auto attack/defend detector is experimental and must be calibrated.
- Second-tap windows and power hold behavior need physical device/in-game tuning.
- Controller commands are not all verified against FC 27 in-game mappings, and some are context-specific.
