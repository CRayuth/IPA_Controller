# Edit and resize the interface

1. During MATCH, tap **EDIT**.
2. Select a control and drag it to the preferred location.
3. Use the slider at the bottom to change the selected button's size (55% to 190%).
4. Tap **RESET** to restore only the selected control or **RESET ALL** to return to defaults.
5. Tap **DONE** to save. Positions and sizes persist using iOS UserDefaults.
6. For overall scaling, open **PC → Button Size** and change global size (80–125%).
7. For placement under the thumb, open **PC → Movement Joystick → Floating**. In EDIT mode, the original fixed stick is shown for repositioning.

Controls may still overlap if enlarged too far on a small screen; decrease global scale or move them with EDIT.
