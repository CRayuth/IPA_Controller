# EA SPORTS FC 27 — Classic controller quick reference

EA's Classic layout is the reference. Choose **Classic** in FC 27's Customize Controls menu.
The app's ATTACK/DEFEND selector changes **labels and shortcuts only**. It does not detect possession.

| In-game action | PlayStation | Xbox | iPhone |
| --- | --- | --- | --- |
| Move | LS | LS | Left stick |
| Skills/change player | RS | RS | Right stick |
| Sprint | R2 | RT | R2, or Sprint Lock |
| Pass / contain | Cross | A | × / A |
| Through pass / GK rush | Triangle | Y | △ / Y |
| Shoot / tackle | Circle | B | ○ / B |
| Cross / slide tackle | Square | X | □ / X |
| Player switch | L1 | LB | L1 |
| Jockey | L2 | LT | L2 |
| Teammate press | R1 | RB | R1 |
| Finesse shot | R1 + Circle | RB + B | FINESSE (hold to charge) |
| Chip shot | L1 + Circle | LB + B | CHIP SHOT (hold to charge) |
| Power shot | L1 + R1 + Circle | LB + RB + B | POWER SHOT (hold to charge) |
| Driven pass | R1 + Cross | RB + A | DRIVEN PASS |
| Curved run | L1 + R1 | LB + RB | CURVED RUN (tap) |
| Pass + follow | L1 + R1 + Cross | LB + RB + A | PASS + FOLLOW |
| Sprint jockey | L2 + R2 | LT + RT | SPRINT JOCKEY |
| Hard tackle | R1 + Circle | RB + B | HARD TACKLE |

A quick-action button holds its underlying normal controller inputs only while you touch it.
It does not auto-play, time shots, select players, or control the game independently.

**Tips**

- Long-press SHOOT or FINESSE for greater shot power, then release.
- Turn Sprint Lock OFF before set pieces and menus. It is optional and starts OFF.
- Use a stable private Wi-Fi network. Keep the Windows receiver running.
- Test in Windows `joy.cpl`, then FC 27 Practice Arena before competitive games.
- One/two-button simplified EA presets are not permitted in competitive online modes; this app uses manual combinations with Classic, not those presets.
